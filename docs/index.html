Baseline

EncryptedGuru Infrastructure v0.1

The initial system uses Google Workspace for identity, encryptedguru.com for naming, Google Cloud for deployable infrastructure, and NVIDIA DSX Air for network simulation. The first objective is not scale. The first objective is clarity.

  • Every service should have a named owner, purpose, and recovery path.
  • Every public endpoint should be documented before it becomes important.
  • Secrets should not appear in notebooks, screenshots, logs, or public repositories.
  • Automation should remain observable and reversible.
  • Public pages should stay static unless dynamic behavior has a clear operational purpose.

Runbook

First operating rules

  • Use domain-based email for infrastructure accounts.
  • Keep billing, operations, contact, and security aliases separate.
  • Use static public pages before adding dynamic systems.
  • Simulate network changes before deploying them to real infrastructure.
  • Keep marketing, analytics, and tracking disabled until there is a clear reason.
  • Prefer boring recovery over clever architecture.
